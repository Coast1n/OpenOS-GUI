# 测试与验收

前十批已通过，首版最小范围完成。最近见 [第十批记录](results/STAGE10.md)：253 项检查、真实 run 与回调异常清理、实际 basic 示例通过。历史执行步骤见 [STAGE10.md](STAGE10.md)，安装使用见 [INSTALL.md](../docs/INSTALL.md)。保留所有历史失败与成功报告；未来改动按范围选择回归并保留必要真实设备验收。

实现后，按模块风险增加测试：

- 可在普通 Lua 5.3 中验证的逻辑：矩形裁剪、控件命中、父子坐标、事件分发和失效范围。
- GPU 模拟：记录绘制调用，验证裁剪边界、颜色与状态恢复；不把模拟结果视作真实 GPU 验证。
- 生命周期与分发：部分启动失败回滚、回调异常与清理异常并存、close 幂等、宿主模式不额外拉取事件、重复 GPU 占用拒绝。
- 交互状态：重叠命中、禁用区域阻挡、冒泡消费、回调中移除控件、捕获与焦点取消、丢失释放超时、多输入来源隔离。
- OpenOS 游戏内：无 GPU、屏幕绑定、中文与宽字符、触摸、拖动、滚轮、键盘输入、正常退出和异常退出。

首个最小验收程序应创建一个标签和一个按钮，点击按钮可改变标签，退出后终端可继续使用。记录实际 GTNH、OpenComputers 和 OpenOS 版本、GPU/屏幕条件、操作步骤及结果；未经运行的项目标为待验证。

本地缺少 Lua 解释器时，完成可用的静态检查并报告限制，不自行安装全局工具。

待实现契约见 [结构设计](../docs/ARCHITECTURE.md) 和 [API 草案](../docs/API.md)。功能实现后再增加对应测试，不将模拟通过或早期批次通过视作后续功能已通过。
